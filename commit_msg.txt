⚡ Bolt: [Physarum Optimization]

💡 What:
Optimized the physarum post-processing effect inner loops. Specifically, removed `mut` variable intermediate states when checking wrap bounds in the `sense` closure by switching to `if/else` assignments, and manually unrolled the per-pixel alpha blending math inside the main rendering loop to avoid overhead of structural unpacking (`Color::from_argb_u32` -> `blend_over` -> `to_argb_u32`).
Added missing `#[cfg(feature = "parallel")]` attribute in `havoc_tile_ub_test.rs` to fix broken test suite under specific features.

🎯 Why:
The TDD cycle detected performance bottleneck within the inner loops. The wrapping conditions inside the sense loop and the per-pixel color blending math inside the render loop were computationally heavy.

📊 Impact:
The benchmark results indicate a ~27% performance improvement:
`physarum_step time: [16.257 ms 16.279 ms 16.302 ms]`
`change: [-27.875% -27.089% -26.257%]`

🔭 Measurement:
Validated using `cargo bench --bench physarum_bench --features nova`. Passed `cargo test -p abrash-render --features nova` and `cargo clippy -p abrash-render --features nova -- -D warnings`.
