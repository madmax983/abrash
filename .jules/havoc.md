**2024-04-12 - Tile and Clipping Buffer Undefined Behavior**
**Threat:** Public `count` fields on custom stack-allocated `MaybeUninit` array structures (`ClippedTriangles`, `PreparedTrianglesList`, `PreparedTexturedTrianglesList`, `PreparedGouraudTrianglesList`) allowed users to bypass memory initialization boundaries. By artificially inflating `count`, subsequent iterators and indexers would read uninitialized memory (Undefined Behavior).
**Defense:** Encapsulated `count` behind a private field and exposed it immutably via an inline `pub const fn count(&self) -> usize` getter method, strictly enforcing boundary integrity.
**2024-04-12 - Tile and Clipping Buffer Undefined Behavior**
**Threat:** Public `count` fields and `tris` arrays on custom stack-allocated `MaybeUninit` structures (`ClippedTriangles`, `PreparedTrianglesList`, `PreparedTexturedTrianglesList`, `PreparedGouraudTrianglesList`) allowed users to bypass memory initialization boundaries or write uninitialized data. By artificially inflating `count`, subsequent iterators and indexers would read uninitialized memory (Undefined Behavior).
**Defense:** Encapsulated both `count` and `tris` arrays behind private fields and exposed `count` immutably via an inline `pub const fn count(&self) -> usize` getter method, strictly enforcing boundary and initialization integrity.
