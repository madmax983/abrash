**Vector Pre-allocation and extend vs push**
**Learning:** Using `reserve_exact` followed by `.extend()` instead of a manual `.push()` loop allows the standard library to completely optimize away the implicit bounds checks on every insertion. Furthermore, calling `reserve` before `reserve_exact` is redundant. Also, trying to replace `.collect::<Vec<_>>()` with `.with_capacity()` and `.extend()` for standard Iterators that implement `TrustedLen` provides zero performance benefit and is an anti-pattern.
**Action:** Always prefer `.extend()` combined with standard map iterators when populating a `Vec` to avoid inner-loop bounds checks, while ensuring `reserve_exact` is used exactly once.
