**Optimize clear_rect operations**
**Learning:** For 2D region fills (like `clear_rect`), the optimal pattern is combining outer-loop iterator chunking (`.chunks_exact_mut(w)`) with inner-loop unsafe slice access (`row.get_unchecked_mut(sx..ex).fill(color)`). This outperforms manual 1D index calculations by giving LLVM strict non-aliasing guarantees while skipping inner bounds checks.
**Action:** Replaced manual 1D index loop and pointer arithmetic with `.chunks_exact_mut` and `.get_unchecked_mut` in `Framebuffer::clear_rect` and `ZBuffer::clear_rect` yielding small performance improvements while remaining clean.
