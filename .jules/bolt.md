**[Hash Map Optimization]
**Learning:** To prevent dynamic heap reallocations when mapping over complex iterators, pre-allocate the target vector using `Vec::with_capacity` and use `.extend()`. However, do not apply this to iterators that already implement `ExactSizeIterator` and `TrustedLen` (e.g., slice iterators). For these, `.collect::<Vec<_>>()` automatically pre-allocates the exact capacity via `FromIterator`, making manual pre-allocation a placebo optimization.
**Action:** Before optimizing `.collect()`, always check if the underlying iterator yields an exact size. If yes, leave it alone. Focus on swapping `std::collections::HashSet` with fast hashers (like `foldhash::HashSet`) for integer keys or small data types, as this yields proven, measurable benefits.
