**[Title]** Remove Leaky Facade in abrash-render
**Tangle:** The `abrash-render` crate was re-exporting the entire contents of `abrash-core` via `pub use abrash_core::*;` in its `lib.rs` and internally referencing these types as if they were internal modules (`crate::math`, `crate::texture`, etc). This leaked the entire core domain into the render API as a facade and violated the clean crate boundary between core types and rendering logic.
**Blueprint:** Removed the facade re-exports from `abrash-render/src/lib.rs` entirely. Systematically updated all internal imports within `abrash-render` to explicitly use the external crate path (`abrash_core::...`), enforcing a strict unidirectional dependency graph.
