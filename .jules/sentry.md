**Testing struct internal invariants**
**Learning:** When a struct relies on `.expect()` or `.unwrap()` to assert its internal fields remain synchronized (e.g., matching lengths of a color buffer and a depth buffer in `RenderTarget::borrow_mut`), standard API usage prevents triggering these panics. However, if the fields are accessible within the same module (e.g., via `pub(crate)`), a test can directly reassign these fields to corrupt the invariant artificially.
**Action:** Use `#[should_panic(expected = "...")]` alongside direct mutation of module-visible struct fields to verify defensive invariant checks that are normally unreachable via the public API.
